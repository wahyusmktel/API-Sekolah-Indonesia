📖 Dokumentasi Lengkap Endpoint

Daftar semua parameter, format url, dan contoh pemanggilan yang didukung.

GET /sekolah Data Sekolah & Paginasi

Mengambil data sekolah dengan paginasi dan filter fleksibel.

Parameter Query:

Parameter Tipe Default Deskripsi
pageinteger1Nomor halaman
perPageinteger20Jumlah data per halaman (maks. 1000)
jenjangstring-Filter jenjang: SD, SMP, SMA, SMK, SLB
statusstring-Status sekolah: N (Negeri) atau S (Swasta)
npsnstring-Cari langsung berdasarkan 8 digit NPSN
sekolah / qstring-Kata kunci pencarian nama sekolah
provinsistring-Filter nama provinsi (contoh: "Jawa Barat")
kode_propstring-Filter berdasarkan kode provinsi (contoh: "020000")
kab_kotastring-Filter kabupaten/kota (contoh: "Bandung")
kecstring-Filter nama kecamatan
GET /sekolah/:jenjang Shortcut Jenjang

Mengambil data sekolah berdasarkan jenjang tertentu secara langsung.

Pilihan jenjang yang didukung: sd, smp, sma, smk, slb.

Contoh: GET /sekolah/SMK?page=1&perPage=10&status=N
GET /sekolah/s?sekolah={nama} Pencarian Nama

Pencarian data sekolah berdasarkan nama (100% kompatibel dengan API versi terdahulu).

Contoh: GET /sekolah/s?sekolah=telkom&page=1&perPage=5
GET /sekolah/detail/:npsnOrId Detail Satuan Sekolah

Mengambil data spesifik 1 sekolah berdasarkan 8-digit NPSN atau UUID Referensi Dapodik.

Contoh: GET /sekolah/detail/20106343
GET /provinsi, /kabupaten, /kecamatan, /stats Master Data & Statistik

Mendapatkan data wilayah administratif terstandarisasi dan ringkasan kuantitas sekolah.

GET /provinsi
GET /kabupaten?provinsi=Jawa+Barat
GET /kecamatan?kab_kota=Bogor
GET /stats

💻 Contoh Kode Integrasi

Contoh pemanggilan di berbagai bahasa pemrograman favorit Anda.

fetch('https://' + window.location.host + '/sekolah?page=1&perPage=5')
  .then(res => res.json())
  .then(data => {
    console.log('Total:', data.total_data);
    console.log('Sekolah:', data.dataSekolah);
  })
  .catch(console.error);
import requests

url = "https://api-sekolah-indonesia-wahyusmktels-projects.vercel.app/sekolah"
params = {
    "page": 1,
    "perPage": 5,
    "jenjang": "SMK"
}

response = requests.get(url, params=params)
data = response.json()

print(f"Total: {data['total_data']}")
for s in data['dataSekolah']:
    print(f"- {s['npsn']} | {s['sekolah']}")
<?php
$url = "https://api-sekolah-indonesia-wahyusmktels-projects.vercel.app/sekolah?page=1&perPage=5";
$response = file_get_contents($url);
$data = json_decode($response, true);

echo "Total Sekolah: " . $data['total_data'] . PHP_EOL;
foreach ($data['dataSekolah'] as $s) {
    echo "- " . $s['npsn'] . " : " . $s['sekolah'] . PHP_EOL;
}
?>
